\subsection{Aggregator sub-batching}
An aggregator that cannot verify can split a batch of 500 into sub-batches of size $k$, so that a fault
loses only its sub-batch. With the measured cost model $\mathrm{verify}(k)=0.0420+0.0564\,k$~ms, the
cost per delivered signature has an interior optimum.
